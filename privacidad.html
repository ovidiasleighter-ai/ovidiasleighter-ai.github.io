Política de privacidad

Última actualización: 9 de octubre de 2026.

Esta política explica cómo la aplicación SR ENIGMA Publisher trata los datos a los que accede a través de los servicios de API de YouTube.

Qué hace la aplicación

SR ENIGMA Publisher la usa únicamente el propietario del canal de YouTube SR. ENIGMA para gestionar su propio canal: subir vídeos, editar sus datos (título, descripción, etiquetas, miniaturas y subtítulos), organizar listas de reproducción y consultar las estadísticas del canal.

Datos a los que accede

  • Datos del canal SR. ENIGMA: información del canal, vídeos, listas, subtítulos y estadísticas.
  • No accede a datos de otros usuarios ni de sus cuentas.

Cómo se usan y se guardan

  • Los datos solo se usan para publicar y gestionar el contenido del propio canal.
  • No se venden, no se comparten con terceros y no se usan con fines publicitarios.
  • Los permisos de acceso se guardan de forma cifrada en el servicio de integración Composio, solo para poder ejecutar las acciones anteriores.

Servicios de terceros

La aplicación usa los servicios de API de YouTube. Al usarla se aplican las Condiciones del servicio de YouTube y la Política de privacidad de Google.

Cómo retirar el acceso

Puedes retirar el acceso en cualquier momento desde la página de permisos de seguridad de Google: myaccount.google.com/permissions. Si pides que se borren los datos guardados, se eliminarán en un plazo de 7 días.
